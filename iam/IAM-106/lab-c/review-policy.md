# Access Review Policy: Unused Access

**Policy:** Revoke access that has not been used in the last 90 days.

**Set-time use:** Access a role uses only at set times, such as month-end or quarter-end, stays if the job still needs it.

**Before anything is removed:** check that every Revoke line really breaks this policy. A wrong revoke stops someone doing their job.

Built during SkillCube IAM training. All data is fictional (Prayan Bank).
